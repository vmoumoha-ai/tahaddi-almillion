# تحدّي المليون

لعبة أسئلة عربية تعمل في المتصفح باستخدام HTML وCSS وJavaScript فقط.

## الملفات
- `index.html` واجهة اللعبة.
- `style.css` التصميم المتجاوب.
- `script.js` الأسئلة وقواعد اللعب ووسائل المساعدة.

## التشغيل محلياً
افتح `index.html` مباشرة في متصفح حديث.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع الملفات الثلاثة إلى المجلد الرئيسي للمستودع.
3. افتح **Settings → Pages**.
4. تحت **Build and deployment** اختر **Deploy from a branch**.
5. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
6. انتظر حتى يظهر رابط الموقع في صفحة Pages.

## التخصيص
يمكنك تعديل الأسئلة في مصفوفة `questions` داخل `script.js`. لكل سؤال:
- `q`: نص السؤال.
- `a`: مصفوفة من أربعة اختيارات.
- `c`: رقم الإجابة الصحيحة، ويبدأ العد من الصفر (0 إلى 3).

اللعبة ترفيهية ولا تقدم جوائز مالية حقيقية. لا تستخدم شعارات أو مواد محمية من البرنامج التلفزيوني.
